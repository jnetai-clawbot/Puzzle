# Puzzle

Android sliding picture puzzle game.

## Features
- Choose from 96 built-in images
- Upload your own image to play as a puzzle
- Random Puzzle button - instantly turns a built-in image into a game
- Settings: grid size (3x3 to 6x6), optional countdown timer (off by default)
- Works with portrait and landscape images, auto-fits without stretching
- Pinch to zoom / resize the puzzle image
- Mark favourite images and hide the ones you don't want to see
- Dark professional theme, room at the bottom so nothing gets cut off

## Building
Built and released automatically via GitHub Actions (push a `v*` tag), never
locally. Signing uses the repo's own keystore so the app updates in place
without uninstallation.
